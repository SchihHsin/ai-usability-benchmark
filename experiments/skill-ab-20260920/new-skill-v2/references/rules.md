# 实验规则 exp-20260920-new

本文件为本副本唯一评分规则。1—10有序五档，M11连续百分制；未知保留null，不借旧规则补分。


## M1 官方可发现性

就这个任务做常规检索，官方文档能不能出现、排名靠不靠前、几轮命中。测的是"找得到官方源"这件事本身。

1. 在预先规定的统一搜索预算内，未发现相关官方来源

2. 第三次或之后的查询才首次发现相关官方来源

3. 第二次查询才首次发现相关官方来源

4. 首次查询第2—5条出现相关官方来源

5. 首次查询第1条即为相关官方来源

试用协议每次观察前5条，最多4次查询；预算是实验条件，不是通用评分定义。查询而非调用计数，批量与并行须统一协议。首次命中后继续检索不降分，改写本身不另扣分。前序超时、列表缺失或未完成预算且未命中记待定。保存每轮全部网址与精确排名。此五档是研究约定，不是已验证量表。

依据边界：具体五档与阈值属于本研究操作化约定，下列文献仅支持相应测量原则，不直接验证本五档。


## M2 官方可抓取性

找到官方页后，web_fetch 能不能真的把正文取回上下文：静态页可抓 vs SPA 单页应用只回导航 / robots 拦截。

1. 未取得可识别的目标页面内容：请求失败、拒绝访问、错误页或无返回

2. 取得目标页面标题、导航或元数据，但没有可识别正文

3. 只取得明确标注为摘要或摘录的正文表示，未取得直接正文返回

4. 取得直接正文，但工具明确标注截断、缺页，或可核对的正文边界存在缺失

5. 取得直接正文，且有可核对的全文/完整目标章节起止依据，无截断或缺页证据

按每个独立官方文档的最终获取状态判定。先区分无内容、框架、摘要/摘录、直接正文，再核对直接正文是否完整。摘要中含代码不自动升级；工具自称完整提取不能独自证明完整。只有直接正文但完整性未知时保留4—5候选范围与待定，不强打4分。获取目标须在读取前明确，不能事后缩小成恰好返回的段落。复合返回如完整正文加摘要按正文证据判定；整份返回为摘要且含原文片段仍属3分。M3评内容是否详尽，M4评版本；不借答案质量判断获取状态。不同独立文档等权平均，保留原始均值；重试不重复计入，未知项不能删除后平均。

依据边界：五档是本研究按获取表示和完整性定义的有序量规，不是假定已知整页覆盖率。正文抽取文献支持区分正文与模板；不直接验证这五个等级，也不保证摘要总比截断正文信息少。


## M3 官方正文详尽度

真正取回的官方正文里，有用信息是否足够细：完整参数表、分步命令、可用的配置 JSON、约束说明，而不只是一句话概述。

1. 取得的正文只有概述，没有相关解释或操作细节

2. 有相关细节，但只有零散参数、片段或说明，不能组成完整解释或操作段落

3. 有完整解释或操作段落，但完成原题所需的关键步骤、参数或约束仍缺失

4. 原题所需主流程及其参数、前提已说明，但原题明确涉及的分支、约束或参考细节未说明完整

5. 原题要求的解释、步骤、参数和约束均说明完整，无需另查才能补齐这些内容

先从原题列出需要说明的内容，禁止添加题外的穷尽要求；每项缺口附正文位置。按最高满足档判定。取不到正文记受阻，不给1分；仅导航或元数据归M2。版本选择归M4。文档内容错误另记，不能只因长而判详尽。

依据边界：具体五档与阈值属于本研究操作化约定，下列文献仅支持相应测量原则，不直接验证本五档。


## M4 版本清晰度

官方源里容不容易选对版本：是单一主线版本，还是多套版本号并存散乱（商用版 / 社区版 / alpha / RC 交错）。

1. 已取得相关官方正文，但其中没有可辨识的版本信息

2. 出现版本信息，但不能确定应选哪版；原因是选择条件缺失或版本说明互相冲突

3. 能排除部分版本或确定版本范围，但仍不能确定一个有明确依据的适用选择

4. 可依据明确条件选定适用版本，但需要跨已取得的官方页面对照才能确定

5. 在同一官方页面内即可依据明确条件选定适用版本，包括清楚的单一版本说明或支持矩阵

先判断版本选择是否明确，再区分已明确选择是页内完成还是跨页对照。4/5区分是可复核的组织位置代理，不能解释为实测耗时。多个版本、多个组件或支持矩阵本身不扣分。记录备选版本、选择条件、引用位置；3分须列出尚不能消除的选择。检索调用代价归M8，最终答案定版归M9。 评价对象是官方资料，不用最终答案是否定版给分。

## M6 二手可信度 / 一致性

二手源权威吗、够新吗、彼此对得上吗：作者/平台可靠度、日期新鲜度、多源结论是否一致（还是互相矛盾、引用过时版本）。

1. 存在与可靠核对依据直接矛盾的关键说法，尚未解决

2. 未发现已确证的关键矛盾，但关键说法没有可追溯的核对依据

3. 有可追溯依据支持部分关键说法，其他关键说法尚未核验

4. 全部关键说法均有可追溯依据支持，未见未解决矛盾，但缺少独立来源的交叉印证

5. 全部关键说法均有可追溯依据支持，并获独立来源交叉印证，未见未解决矛盾

关键说法限于会改变操作、解释或版本判断的可核验陈述，逐条记录支持/反驳/未知。权威性依据作者身份、第一手材料或可复核实验证据，不按平台名直接给分。转载不构成独立互证；旧文只有在内容已失效时才作为反证。没有第三方材料记N/A。此五档是证据可信程度量规，尚未校准。

## M9 版本可锁定性

最终答案能不能定到确切版本（库版本 / 工具链版本 / soc_version 等），而不是含糊地"某个版本应该可以"。

1. 最终答案未提供原题需要的版本信息

2. 提到版本，但没有给出有依据的适用版本或范围，或关键定版与证据矛盾

3. 部分所需组件有明确版本依据，其余仍未确定

4. 所有所需组件均给出有依据的适用范围，但至少一项尚未定到具体版本

评价对象仅为最终答案。先固定原题实际需要定版的组件；不强制无关opset。符合证据的范围不等于答案错误，但锁定粒度低于具体版本。无版本需要记N/A；不能为提高分数随意指定版本。 与M4区别：本项只看最终答案，官方资料清楚不代表答案已定版。
