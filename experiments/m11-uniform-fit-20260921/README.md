## 系数隔离

任务执行模型不自行计算或报告正式 M11。旧系数 a=0.3、b=0.1 仅作为事后对照；上一轮拟合结果不作初始化、默认值或选择依据。新系数在预先声明的全网格上用开发集选择，冻结之后才评估留出集。正式 Skill 暂不替换。

## 论文留存

保留原问题及来源哈希、任务选择理由、Skill快照、协议与修订、可见提示词、模型标识、完整检索返回与获取文本、检索前及最终答案、预算账本、失败尝试、逐项证据评价、拟合代码、候选模型与留出结果。每次运行主文件仍为 process.jsonl 和 evaluation.json。

预算两档是资源条件设计，不是文献证明的最佳次数。拟合目标是证据支持的答案质量代理，不是上卡成功率，也不能据此声称 M11 是校准后的正确概率。若证据不足或系数仍不稳定，将如实保留不确定性，不强行宣布最优值。
