# 执行检查（分档不变）

开始运行前读取任务包中本侧applicability；M4/M9只检查该范围中实际采用路线的版本适用关系，不要求列全替代工具，也不要求无题目依据的升级方案。Z为概念题，M4/M9/M10=N/A。E诊断题检查诊断接口/工具的适用条件，不追加完整环境配套任务。无本机版本时允许有依据的条件范围，不强指定某版本。M9仍按已确认锁定粒度评分；这不代表范围答案技术错误。

先验必须在第一次工具调用前保存。优先使用闭合prior_answer；漏闭合时只能按首次工具事件之前的可见回答边界恢复，留存恢复标记，不读检索后文本补先验。

后评以原题请求为要求，逐子要求列证据，不机械要求六项。M2清单必须覆盖所有fetch返回，明确official/third_party/unknown；同请求URL去fragment合并重试，不合并未知重定向或镜像。未知归属使聚合待定，不能静默删掉。最后一次派发的返回决定当前文档状态；早期障碍独立留存。

M2正文完整性字段complete/incomplete/unknown；complete须有独立核对依据，工具自称完整不够。正文未知为[4,5]，表示未知可保留[1,5]；无内容/框架/明确摘要分别1/2/3。逐项区间等权平均，由程序计算，不接受模型自填均值。事后参照仅用于评价，不加入当时上下文或M8。

M4评分附m4_check：required_relations（固定范围）、missing_relations、unresolved_conflicts、determination（none/partial/combined/direct）、evidence。存在缺失关系不能打4/5；冲突未消解不能打3/4/5。4分必须说明哪些官方约束合并得到何种适用关系；5分必须引用直接适用表/规则。机器检查这些字段的逻辑一致性和引文，技术含义仍需复核，不声称自动检查能验证真伪。正文未取得不代表官网缺少版本说明。

引用必须event_id+逐字quote：M9/M10只引用最终答案，M7引用检索前答案，其他来源指标引用真实来源。无引用的点分不能通过。保存原始后评，派生评价另存；不得为通过验证虚构引文。未做评价记not_assessed，评价后证据仍不足才记insufficient_evidence。

M11按下述缺失、区间和不适用约定计算。既有材料复核、引文修复不是任务重跑。

## M11缺失、区间和不适用的计算约定

原公式与0.30/0.10系数不变。普通分项以Mi/5归一化；bounded输入保留下上界，利用公式在各输入上的单调性计算综合上下界，显示时向外舍入，不取中点冒充精确分数。此区间不是统计置信区间。

channel_states的official/third_party/prior仅在证据复核确认该渠道在本轮确实无可用支撑时设confirmed_unavailable，必须附reason与evidence。该渠道贡献置0，不要求对不存在的下游材料补分。不得仅凭一个页面失败、M5=1、M6=N/A或一次错误主张自动判整条渠道不可用；完整检索预算内无相关第三方来源才可据此判第三方渠道无支撑。先验未保存不等于无先验。该状态由复核材料提供，不接受执行模型自报。

任务预设M4不适用时，版本调整因子为1（中性，不折减），原M4仍N/A，不能记为5分。此为不适用处理约定，不是文献证明的最优系数；含N/A任务单独标识，不据此与版本相关任务直接排名。M8缺失或异常中断不能作中性处理。

尚未评价、日志缺失或无可用界限仍报告incomplete_inputs及逐项原因，不静默补0。正常的区间结果不算未完成；真正待补评的条目须单列。计算器只校验输入结构和算术；证据是否足以支持渠道无支撑，由引文门禁与内容复核负责。
