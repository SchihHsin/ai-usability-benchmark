Python\n\nPython pass 和 C++ pass 使用同一套 GE 匹配替换机制，但 Python 更适合快速开发和运行时接入：\n\n- **接入便利**：把 `.py` 文件或目录配置到 `ASCEND_GE_PY_PASS_PATH`，GE 编译阶段会运行时加载，不需要先把 pass 编译成 `.so`。\n- **表达更短**：`@pattern` 可以用 Python 表达式描述 pattern，例如 `return inputs[0] + 0`。\n- **replacement 更直观**：简单替换可以直接写 `return inputs[0]`，不用手动创建 replacement graph。\n- **便于迭代**：修改 Python 文件后重新触发编译即可验证，适合先把规则跑通。\n\n## [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#2-%E6%9C%80%E5%B0%8F%E7%A4%BA%E4%BE%8B%E5%88%A0%E9%99%A4-addx-0)2. 最小示例：删除 Add(x, 0)\n\n目标：把图中的 `Add(x, 0)` 替换成 `x`。\n\n```text\nx ----\\\n       Add ---- out      ==>      x ---- out\n0 ----/\n```\n\nPython 写法如下：\n\n```python\nfrom math import fabs\n\nfrom ge.graph.types import DataType\nfrom ge.passes import PassStage, PatternFusionPass, pattern, register_fusion_pass\n\n\ndef _scalar_value(value):\n    while isinstance(value, list):\n        if len(value) != 1:\n            return None\n        value = value[0]\n    return value\n\n\ndef _is_zero(tensor):\n    value = _scalar_value(tensor.data)\n    if value is None:\n        return False\n    if tensor.data_type == DataType.DT_FLOAT:\n        return fabs(float(value)) < 1e-6\n    if tensor.data_type == DataType.DT_DOUBLE:\n        return fabs(float(value)) < 1e-15\n    if tensor.data_type == DataType.DT_INT32:\n        return int(value) == 0\n    return False\n\n\n@register_fusion_pass(name=\"PythonAddZeroPass\", stage=PassStage.BEFORE_INFER_SHAPE)\nclass PythonAddZeroPass(PatternFusionPass):\n    @pattern\n    def add_zero(self, inputs):\n        return inputs[0] + 0\n\n    def meet_requirements(self, match_result):\n        for node in match_result.get_matched_nodes():\n            if node.type != \"Const\":\n                continue\n            return _is_zero(node.get_attr(\"value\"))\n        return False\n\n    def replacement(self, inputs):\n        return inputs[0]\n```\n\n这段代码里只有三件事：\n\n1. `@pattern` 方法描述要找的结构：第 0 个外部输入加一个常量。\n2. `meet_requirements` 检查命中的常量是否真的是 0。\n3. `replacement` 返回第 0 个外部输入，相当于删除这次命中的 `Add`。\n\n完整可运行样例见 [AddZeroPass Python 样例](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/pattern_base_pass/4_add_zero_pass/python/README.md)。\n\n## [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#3-%E5%86%99%E4%B8%80%E4%B8%AA-patternfusionpass-%E7%9A%84%E6%AD%A5%E9%AA%A4)3. 写一个 PatternFusionPass 的步骤\n\n### [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#31-%E5%BC%95%E5%85%A5%E6%8E%A5%E5%8F%A3)3.1 引入接口\n\n常用导入如下：\n\n```python\nfrom ge.passes import (\n    PassStage,\n    PatternFusionPass,\n    pattern,\n    register_fusion_pass,\n)\n```\n\n如果要写 `DecomposePass`，还需要：\n\n```python\nfrom ge.passes import DecomposePass, register_decompose_pass\n```\n\n接口完整说明见 [Python Passes API](https://gitcode.com/cann/ge/blob/develop/docs/en/user_guides/ge_python/api/Passes.md)。\n\n### [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#32-%E6%B3%A8%E5%86%8C-pass)3.2 注册 pass\n\n用 `@register_fusion_pass` 把类注册给 GE：\n\n```python\n@register_fusion_pass(name=\"MyPass\", stage=PassStage.BEFORE_INFER_SHAPE)\nclass MyPass(PatternFusionPass):\n    ...\n```\n\n`name` 必须唯一。`stage` 表示执行阶段。初次开发建议使用 `PassStage.BEFORE_INFER_SHAPE`，因为 replacement 后还能进入 GE 后续统一的 shape 推导流程。\n\n### [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#33-%E7%94%A8-pattern-%E5%AE%9A%E4%B9%89%E8%A6%81%E5%8C%B9%E9%85%8D%E7%9A%84%E7%BB%93%E6%9E%84)3.3 用 @pattern 定义要匹配的结构\n\n`@pattern` 方法接收一个 `inputs` 对象。它代表 pattern 的外部输入集合。\n\n```python\n@pattern\ndef add_zero(self, inputs):\n    return inputs[0] + 0\n```\n\n这里的 `inputs[0]` 是第 0 个外部输入占位符，不是某个固定真实节点。匹配时，GE 会把真实图中连进这段结构的 Tensor 对应到它。\n\n多输入场景可以这样写：\n\n```python\n@pattern\ndef matmul_add(self, inputs):\n    a, b, c = inputs[:3]\n    return MatMul(a, b) + c\n```\n\n注意：\n\n- `inputs[i]` 会按需创建第 `i` 个输入。\n- `inputs[:N]` 用于显式声明连续的多个输入。\n- `@pattern` 会自动 capture 已访问的外部输入和返回的 pattern 输出。capture 顺序固定为：先按输入序号 capture 外部输入，再按 `return` 结构顺序 capture pattern 输出。以上例为例，`a/b/c` 会分别作为第 0/1/2 个 captured tensor，`MatMul(a, b) + c` 的输出会作为第 3 个 captured tensor 出现在 `match_result` 中。\n- 不要直接遍历 `inputs`，因为输入个数不是预先固定的。\n- 一个 `@pattern` 方法只表示一个 pattern。\n- 多个拓扑要写多个 `@pattern` 方法。\n- `@pattern` 不能和 `patterns(self)` 同时使用。\n\n### [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#34-%E7%94%A8-meet_requirements-%E5%81%9A%E6%9D%A1%E4%BB%B6%E8%BF%87%E6%BB%A4%E5%8F%AF%E9%80%89)3.4 用 meet_requirements 做条件过滤（可选）\n\n如果拓扑命中后还要检查 dtype、shape、属性、常量值，就实现 `meet_requirements`：\n\n```python\ndef meet_requirements(self, match_result):\n    for node in match_result.get_matched_nodes():\n        if node.type == \"Const\":\n            return _is_zero(node.get_attr(\"value\"))\n    return False\n```\n\n`match_result` 是这次匹配的结果。它可以拿到命中的真实节点，也可以拿到 pattern 中捕获的 Tensor。使用 `@pattern` 时，pattern 中已访问的外部输入会按输入序号自动 capture，`return` 的 pattern 输出会随后按返回顺序自动 capture；未作为 `return` 输出的中间 Tensor 不会自动 capture。\n\n如果只要拓扑匹配成功就替换，可以不写这个方法；默认返回 `True`。\n\n如果meet_requirements()方法需要读取编译选项或设置错误信息，可以在参数末尾声明`context`：\n\n```python\nfrom ge.passes import PassContext\n\n\ndef meet_requirements(self, match_result, context: PassContext):\n    return context.get_option_value(\"ge.custom.enable_rule\") == \"1\"\n```\n\n### [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#35-%E7%94%A8-replacement-%E5%AE%9A%E4%B9%89%E6%9B%BF%E6%8D%A2%E7%BB%93%E6%9E%84)3.5 用 replacement 定义替换结构\n\n最简单的 replacement 可以直接返回某个输入：\n\n```python\ndef replacement(self, inputs):\n    return inputs[0]\n```\n\n也可以用表达式创建新结构：\n\n```python\ndef replacement(self, inputs):\n    a, b, c = inputs[:3]\n    return GEMM(a, b, c, 1.0, 1.0)\n```\n\n如果 replacement 需要读取匹配到的节点属性，可以多接收一个 `match_result` 参数：\n\n```python\ndef replacement(self, inputs, match_result):\n    a, b, c = inputs[:3]\n    transpose_a = False\n    transpose_b = False\n    for node in match_result.get_matched_nodes():\n        if node.type not in (\"MatMul\", \"BatchMatMulV2\"):\n            continue\n        try:\n            transpose_a = bool(node.get_attr(\"transpose_x1\"))\n            transpose_b = bool(node.get_attr(\"transpose_x2\"))\n        except RuntimeError:\n            pass\n        break\n    return GEMM(a, b, c, 1.0, 1.0, transpose_a, transpose_b)\n```\n\n如果 replacement 需要同时读取匹配详情和编译期上下文，可以多接收一个`context`参数：\n\n```python\ndef replacement(self, inputs, match_result, context: PassContext):\n    a, b, c = inputs[:3]\n    if context.get_option_value(\"ge.custom.enable_rule\") != \"1\":\n        context.set_error_message(\"rule is disabled\")\n    return GEMM(a, b, c, 1.0, 1.0)\n```\n\n如果 replacement 只需要编译期上下文，也可以使用`replacement(self, inputs, context)`。第三个参数只有严格命名为`context`时才按`PassContext`处理，否则按原有语义作为`match_result`传入。未声明`context`的原有写法保持不变。\n\n## [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#4-%E4%BB%80%E4%B9%88%E6%97%B6%E5%80%99%E4%B8%8D%E7%94%A8-pattern)4. 什么时候不用 @pattern\n\n`@pattern` 适合大多数常见拓扑，但它有一个明确边界：它会自动 capture 已访问的外部输入和 `return` 的 pattern 输出，不会自动 capture 未作为输出返回的中间 Tensor。\n\n如果 `meet_requirements` 或 `replacement` 需要读取未作为 `return` 输出的中间 Tensor，例如 `MatMul` 输出，就不要使用 `@pattern`。此时应显式创建 pattern graph，再调用 `Pattern.capture_tensor` 标记需要读取的中间 Tensor。若只需要读取 `return` 返回的最终输出，例如 `Add` 输出，继续使用 `@pattern` 即可。\n\n这种写法更接近 C++：\n\n```python\nfrom ge.es.graph_builder import GraphBuilder\nfrom ge.passes import create_pattern, create_replacement\n\n\ndef patterns(self):\n    builder = GraphBuilder(\"pattern\")\n    a, b, c = builder.create_inputs(3)\n    matmul = MatMul(a, b)\n    add = matmul + c\n    pat = create_pattern(builder.build_and_reset([add]))\n    pat.capture_tensor(matmul)\n    pat.capture_tensor(add)\n    return [pat]\n\n\ndef replacement(self, match_result):\n    builder = GraphBuilder(\"replacement\")\n    a, b, c = builder.create_inputs(3)\n    gemm = GEMM(a, b, c, builder.create_scalar_float(1.0), builder.create_scalar_float(1.0))\n    return create_replacement(builder.build_and_reset([gemm]))\n```\n\n如果只是表达 `Add(x, 0)`、`MatMul + Add` 这类规则，优先用 `@pattern`，代码更短也更贴近优化逻辑。\n\n## [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#5-%E6%8D%95%E8%8E%B7-tensor)5. 捕获 Tensor\n\n捕获 Tensor 的作用是：在 pattern 命中后，从 `match_result` 中按捕获顺序取回对应的真实 Tensor。\n\n常见用途：\n\n- 检查某个输出 Tensor 的 dtype 或 shape。\n- 读取原节点属性，传给 replacement 中的新节点。\n- 打印命中位置，确认 pass 是否命中预期节点。\n\n参考 [capture tensor Python 样例](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/pattern_base_pass/2_fuse_matmul_add_pass_with_capture_tensor/python/README.md)。\n\n## [](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/python_fusion_pass_development_guide.md#6-%E6%9B%B4%E4%B8%A5%E6%A0%BC%E7%9A%84%E5%8C%B9%E9%85%8Dpatternmatcherconfig)6. 更严格的匹配：PatternMatcherConfig\n\n默认 matcher 主要检查拓扑和算子类型。如果想在匹配阶段就检查 Const 值，可以在构造函数中传入配置：\n\n```python\nfrom ge.passes import PatternMatcherConfigBuilder\n\n\nclass PythonAddZeroConstValueMatchPass(PatternFusionPass):\n    def __init__(self):\n        super().__init__(\n            PatternMatcherConfigBuilder()\n            .enable_const_value_match()\n            .build()\n        )\n\n    @pattern\n    def add_zero(self, inputs):\n        return inputs[0] + 0.0\n\n    def replacement(self, inputs):\n        return inputs[0]\n```\n\n这个写法更短，但 Const 值匹配是严格匹配，不做浮点容差，也不做跨 dtype 归一化。如果你的判断需要容差或更复杂逻辑，放在 `meet_requirements` 中更稳妥。\n\n参考 [PatternMatcherConfig Python 样例](https://gitcode.com/cann/ge/blob/develop/examples/fusion_pass/pattern_base_pass/3_fuse_matmul_add_pass_with_pattern_matcher_config/python/README.md)。\n\n##
