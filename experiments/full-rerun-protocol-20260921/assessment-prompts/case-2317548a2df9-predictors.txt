**Pattern C（`OpCommand`）** → 否则按是否需要 workspace/tiling 选 **Pattern A 或 B** 自实现 AscendC kernel。三者可共存。**核心原则：能复用优先复用，不重复造轮子。**\n\n### Pattern A：无 workspace（参考 `add`）\n\n- **Kernel**：只有输入输出（可选标量），文件 `csrc/kernel/{kernel_name}_custom.cpp`，流程 `CopyIn -> Compute -> CopyOut`\n- **Host**：只分配输出（`at::empty_like(x)` 或 `at::empty(...)`），调用 `EXEC_KERNEL_CMD({kernel_name}, blockDim, input..., output[, scalars])`；需包含 `aclrtlaunch_{kernel_name}.h`\n- **CMake**：\n  ```cmake\n  ascendc_library(no_workspace_kernel STATIC csrc/kernel/{kernel_name}_custom.cpp)\n  ```\n  并将该库链接进最终共享扩展\n\n### Pattern B：有 workspace 和/或 tiling（参考 `matmul_leakyrelu`）\n\n- **Kernel**：需要 workspace（可选 tiling），同样 `CopyIn -> Compute -> CopyOut`；构建加 `HAVE_WORKSPACE`，用 tiling 再加 `HAVE_TILING`\n- **Host**：分配输出、workspace tensor（大小来自平台接口或用户输入），必要时分配 tiling tensor 并调用 tiling 生成逻辑；最终 `EXEC_KERNEL_CMD({kernel_name}, blockDim, input..., output, workspace[, tiling])`\n- **CMake**：\n  ```cmake\n  ascendc_library(workspace_kernel STATIC csrc/kernel/{kernel_name}_custom.cpp)\n  ascendc_compile_definitions(workspace_kernel PRIVATE -DHAVE_WORKSPACE -DHAVE_TILING)\n  ```\n  tiling 逻辑需把 `csrc/host/tiling/*.cpp` 加入 host 源文件，并把 `workspace_kernel` 链接进最终共享扩展\n\n### Pattern C：复用已有算子（`OpCommand` 模式）\n\n**适用**：算子已完整实现（CANN 内置或 `xpu_kernel`/custom ops 已安装）。\n\n- **基本思路**：直接 `OpCommand` 调图算子名，不新增 AscendC kernel\n- **输入输出命名**：图算子在 `op_def` 定义了名字时，通过第二参数 `descName` 精确对应：`.Input(tensor, \"inputGradY\")`、`.Output(tensor, \"outputGradX\")`\n\n#### 示例 1：`LayerNormV3`（CANN 内置）\n\n- **PyTorch API**：`torch.ops.npu.layer_norm_v3(x, gamma, beta, begin_norm_axis, begin_params_axis, eps) -> (y, mean, rstd)`\n- **实现要点**：\n  - 确保 `x.device().type() == PrivateUse1`\n  - 输出构造：`y = at::empty_like(x)`；`mean/rstd` shape 为 `[A1...Ai, 1...1]`（`i = begin_norm_axis`）\n  - `OpCommand` 调用：\n    ```cpp\n    .Name(\"LayerNormV3\")\n    .Input(x).Input(gamma).Input(beta)\n    .Output(y).Output(mean).Output(rstd)\n    .Attr(\"begin_norm_axis\", (int64_t)begin_norm_axis)\n    .Attr(\"begin_params_axis\", (int64_t)begin_params_axis)\n    .Attr(\"epsilon\", (float)eps)\n    .Run()\n    ```\n\n#### 示例 2：`LayerNormV4`（含可选参数）\n\n- **PyTorch API**：`torch.ops.npu.layer_norm_v4(x, int[] normalized_shape, Tensor? gamma=None, Tensor? beta=None, float eps=1e-5) -> (Tensor, Tensor, Tensor)`\n- **实现要点**：\n  - C++ 签名：`at::IntArrayRef normalized_shape`、`c10::optional<at::Tensor> gamma_opt/beta_opt`\n  - `mean/rstd` shape 为 `[A1...Ai, 1...1]`（`Ai` 为未归一化轴，即 `input.dim() - normalized_shape.size()` 之前的维度）\n  - 调用：\n    ```cpp\n    .Name(\"LayerNormV4\")\n    .Input(x)\n    .Input(normalized_shape)   // host 侧 int list，OpCommand 自动处理 H2D\n    // gamma_opt 有值: .Input(*gamma_opt)，否则 .Input()（空输入映射到 OPTIONAL_INPUT）\n    // beta_opt 同理\n    .Output(y).Output(mean).Output(rstd)\n    .Attr(\"epsilon\", (float)eps)\n    .Run()\n    ```\n\n#### Pattern C 的 CMake 简化（host-only）\n\n```cmake\nfile(GLOB _SRCS csrc/host/*.cpp)\nadd_library({pkg} SHARED ${_SRCS})\ntarget_link_libraries({pkg} PRIVATE torch_npu)\n```\n\n- **include 目录**：`${TORCH_NPU_PATH}/include`、`${TORCH_PATH}/include` 及 `torch/csrc/api/include`、`${ASCEND_CANN_PACKAGE_PATH}/include`（`graph/types.h` 等）；必要时补 `${ASCEND_CANN_PACKAGE_PATH}/runtime/include`\n- **实战建议**：若 PyTorch 未导出 `TorchConfig.cmake`，不要强依赖 `find_package(Torch)`；更稳妥是在 `setup.py` 中用 `torch.utils.cpp_extension.load(...)` 编译，再 `torch.ops.load_library(...)` 加载\n\n#### 面向 `xpu_kernel` / custom ops 的要点\n\n- 图算子名来自 `op_def` 的 `OP_ADD(OpClassName)`（如 `MoeInitRoutingGroupedMatmulGrad`）\n- 输入输出名来自 `this->Input(\"inputGradY\")` 等定义，调用写 `.Input(t, \"inputGradY\")`\n- 输出 shape 需 host 侧按 infer shape 逻辑自行推导（如 `batch = expanded_row_idx.numel() / topk`），与图算子推导一致\n- 前提：`xpu_kernel` 已构建安装，否则运行时报 `\"op not found\"`\n- **工程化建议（容器外驱动案例）**：\n  - `setup.py` 必须补齐 `torch_npu/include` 与 CANN include（否则 `OpCommand.h`/`graph/types.h` 编译失败）\n  - 链接必须链 `libtorch_npu.so`（否则运行时 `undefined symbol OpCommand::Name`）\n  - 验证必须在源码目录外执行\n\n#### 常见注意事项（含 aclnn 相关）\n\n- `OpCommand::Attr` 整型参数统一用 `int64_t`，避免 `OpAttrMaker::Set` 的 `bool`/`int64_t` 重载歧义\n- `normalized_shape` 从 Python 传 `List[int]`，**不要传 Tensor**；C++ 用 `IntArrayRef`\n- 可选张量参数用 `Tensor?` 配合空 `.Input()`，不要用占位张量\n- **若底层已有 `aclnn_layer_norm*` 这类 C API，优先通过 `OpCommand` 调图算子，而不是手工处理 `aclTensorDesc` / `aclDataBuffer` / `aclnn*GetWorkspaceSize`**\n- `setup.py` 用 `os.F_OK` 和 `os.X_OK`，不要写不存在的 `os.path.F_OK`\n- **不要把 `TORCH_LIBRARY_*` 注册库当 Python 扩展模块导入**：只注册 `torch.ops.npu.*` 的 `.so` 通常无 `PyInit_*` 入口，应通过 `torch.ops.load_library(...)` 加载，而非 `import _C`\n- 用 `torch.utils.cpp_extension.load(...)` 生成 Pattern C 共享库时，通常显式 `is_python_module=False`\n\n> **核心结论**：先判断算子是否已存在（CANN 或 `xpu_kernel`）；已存在通常只需加一个 PyTorch host wrapper。\n\n---\n\n## 七、Kernel 实现\n\n- 新增 `csrc/kernel/{kernel_name}_custom.cpp`，逻辑遵循 `CopyIn -> Compute
