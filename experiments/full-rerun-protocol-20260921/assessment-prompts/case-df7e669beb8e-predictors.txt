profiler_config.json 控制配置，**不需要修改用户代码** |\n| 添加 dynamic_profile 接口方式 | 支持训练/在线推理，通过修改配置文件控制启动，需预先在脚本中添加接口 |\n| 添加 dp.start() 函数方式 | 支持训练/在线推理，自定义 start 位置，适合缩小采集范围 |\n\n**（1）环境变量方式**\n\n```bash\nexport PROF_CONFIG_PATH=\"/path/to/profiler_config_path\"\n```\n\n配置后启动训练，会自动在 profiler_config_path 下创建模板文件 profiler_config.json。\n\n限制：\n- 该方式**不支持采集第一个迭代的数据**\n- 依赖 torch 原生 `Optimizer.step()` 划分 step，**不支持自定义 Optimizer 场景**\n- 路径格式仅支持由字母、数字和下划线组成，**不支持软链接**\n\n**（2）添加 dynamic_profile 接口方式**\n\n```python\n# 加载dynamic_profile模块\nfrom torch_npu.profiler import dynamic_profile as dp\n# 设置Profiling配置文件的路径\ndp.init(\"profiler_config_path\")\n...\nfor step in steps:\n    train_one_step()\n    # 划分step\n    dp.step()\n```\n\n**（3）添加 dp.start() 函数方式**\n\n```python\nfrom torch_npu.profiler import dynamic_profile as dp\ndp.init(\"profiler_config_path\")\n...\nfor step in steps:\n    if step==5:\n        # 设置start接口Profiling配置文件路径\n        dp.start(\"start_config_path\")\n    train_one_step()\n    # 划分step，需要进行profile的代码需在dp.start()接口和dp.step()接口之间\n    dp.step()\n```\n\nstart_config_path 同样指向 profiler_config.json，但需手动创建并配置参数，须指定具体文件名，例如 `dp.start(\"/home/xx/start_config_path/profiler_config.json\")`。\n\n**dynamic_profile 通用行为说明：**\n- 每 **2s 轮询**一次 profiler_config.json，发现改动则启动采集；之后记录相邻 step 运行间隔作为新轮询时间，**最小值 1s**\n- 采集执行期间若配置文件被修改，则在采集结束后再次启动最后一次修改对应的采集\n- 建议使用**共享存储**设置 profiler_config_path\n- `start_step` 参数值应大于当前已执行到的 step 且不超过最大 step\n- profiler_config_path 目录下会自动记录维测日志\n\n---\n\n## stream)\ntorch.matmul()\ntorch_npu.npu.mstx.range_pop()\n\n# 只记录Host侧range耗时（进程级）\nid = torch_npu.npu.mstx.range_start(\"dataloader\", None)\ndataloader()\ntorch_npu.npu.mstx.range_end(id)\n\n# 计算流上打点（进程级）\nstream = torch_npu.npu.current_stream()\nid = torch_npu.npu.mstx.range_start(\"matmul\", stream)\ntorch.matmul()\ntorch_npu.npu.mstx.range_end(id)\n\n# with语句调用\nwith torch_npu.npu.mstx.annotate('my_code_range', cur_stream):\n    time.sleep(1)\n\n# 装饰器调用\n@torch_npu.npu.mstx.annotate()\ndef sleep_one():\n    print(\"sleep start\")\n    time.sleep(1)\n schedule=torch_npu.profiler.schedule(wait=0, warmup=0, active=1, repeat=1, skip_first=0, skip_first_wait=0),\n    on_trace_ready=torch_npu.profiler.tensorboard_trace_handler(\"./result\"),\n child_thread):\n    torch.npu.set_device(device)\n\n    if child_thread:\n        # 开始采集子线程的torch算子等框架侧数据\n        torch_npu.profiler.profile.enable_profiler_in_child_thread(with_modules=True)\n\n    for _ in range(5):\n        outputs = model(input_data)\n\n    if child_thread:\n        # 停止采集子线程的torch算子等框架侧数据\n        torch_npu.profiler.profile.disable_profiler_in_child_thread()\n\n\nif __name__ == \"__main__\":\n    experimental_config = torch_npu.profiler._ExperimentalConfig(\n        aic_metrics=torch_npu.profiler.AiCMetrics.PipeUtilization,\n        profiler_level=torch_npu.profiler.ProfilerLevel.Level1\n    )\n\n    prof = torch_npu.profiler.profile(\n        activities=[torch_npu.profiler.ProfilerActivity.CPU, torch_npu.profiler.ProfilerActivity.NPU],\n        on_trace_ready=torch_npu.profiler.tensorboard_trace_handler(\"./result\"),\n        record_shapes=True,\n        profile_memory=True,\n        with_stack=False,\n        with_flops=False,\n        with_modules=True,\n        experimental_config=experimental_config)\n\n    prof.start()\n\n    threads = []\n    for i in range(1, 3):\n        # 创建2个子线程，分别在device1与device2上进行推理任务\n        t = threading.Thread(target=infer, args=(i, True))\n        t.start()\n        threads.append(t)\n\n    # 主线程在device0上运行推理任务，由Profiler正常采集\n    infer(0, False)\n\n    for t in threads:\n        t.join()\n\n    prof.stop()\n```\n\n生成的子线程性能数据中，aten 前缀的 timeline 即为子线程采集到的 torch 算子数据。\n\n---\n\n## 七、离线解析\n\n**功能**：采集数据较大时，取消 `on_trace_ready`
